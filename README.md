# 🎮 天枢 (Tianshu) - Minecraft AI 助手

> 你的 Minecraft 语音 AI 伙伴，完全本地运行，无需 API Key，一键安装即可使用。

---

## ✨ 为什么选择天枢？

### 🤖 完全本地运行
天枢的所有 AI 能力（语音识别、大语言模型、语音合成）都运行在你的电脑上。
- 🔒 **隐私安全** - 你的对话数据永远不会离开你的机器
- 💸 **零成本** - 不需要 OpenAI、Mistral 或任何付费 API
- 📡 **离线可用** - 不需要网络连接（下载模型后）

### 🎤 真正的语音交互
不只是文字聊天，而是真正的语音对话：
- 说话就行，模组自动识别并回复
- AI 用语音回答你，不需要看文字
- 全程不需要手动打字

### ⚡ 一键安装，无需折腾
与其他本地 LLM 模组不同：
- ❌ 不需要安装 Ollama
- ❌ 不需要手动下载模型文件
- ❌ 不需要配置 Docker
- ❌ 不需要敲命令行

**天枢只需要：你电脑性能足够好 → 点击安装 → 模组自动下载所需的 AI 模型 → 开始玩！**

### 💪 对性能负责
因为 AI 模型运行在本地，所以：
- 推荐显存 6GB+（用于 LLM 推理）（上不封顶）
- 语音识别和语音合成对硬件要求较低
- 可以在设置里选择不同规模的模型

---

## 🎯 功能一览

### 🎙️ 语音输入
- 说话即可触发识别
- 支持多种语言
- 自动判断是指令还是闲聊

### 💬 智能对话
- 基于本地大语言模型
- 了解游戏内上下文
- 支持多轮对话记忆与长期记忆
- 支持Rag功能，根据游戏状态动态检索相关信息

### 🔊 语音输出
- AI 回复直接用语音说出来
- 支持多种声音风格
- 高端模型支持音色克隆

---

## 💡 我们的方式

天枢采用完全本地化的方案

- 🔑 **无需 API Key** — 不依赖任何云端服务，不按 token 计费，用多少都不花钱
- 🔧 **无需手动部署** — 不用装 Ollama、配 Docker、敲命令行，游戏内一键下载模型即可
- 🎤 **全程语音交互** — 语音输入 + 语音输出，不用在游戏里打字打断操作
- 🔒 **数据不出机器** — 所有对话和推理都在本地完成，隐私有保障

| | 天枢 |
|---|---|
| AI 运行方式 | 内置推理引擎，开箱即用 |
| 模型获取 | 游戏内一键下载 |
| 交互方式 | 语音输入 + 语音输出 |
| 费用 | 完全免费 |
| 隐私 | 100% 本地，数据不出机器 |

> ⚠️ 因为所有 AI 都跑在你自己电脑上，所以对硬件有一定要求（推荐 6GB+ 显存、16GB+ 内存）。性能越好，体验越流畅。

```
    ↓
🧬 织言 (LLM) — 大语言模型推理
    ↓
🔊 回响 (TTS) — 语音合成

```
