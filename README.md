# 🎮 天枢 (Tianshu) - Minecraft AI 助手

> 语音在本机识别与合成，对话交给你自己配置的云端大模型；装好模组，按键说话就行。

---

## ✨ 为什么选择天枢？

### 🎤 语音走本机

听澜负责语音识别，回响负责语音合成，两者都跑在玩家自己的电脑上：

- 🎙️ **麦克风音频不上传** — 识别在本机完成
- 🔊 **回答在本机合成** — 合成语音不经过云端
- 📦 **模型游戏内下载** — 不用装 Ollama、配 Docker、敲命令行

### 🧠 大脑可替换

对话推理由织言接入任意 OpenAI 兼容端点（默认 DeepSeek）：

- 🔑 **用自己的 Key** — 在设置页填端点、Key、模型名即可
- 🔄 **换模型不重装** — 换服务商或换模型只改设置
- 💳 **只为用量付费** — 费用按所选服务商结算，天枢本身不收费

### 🧩 装谁是谁

- 北辰是宿主，负责界面、按键、设置、世界状态和模组装载
- 五个功能模组（听澜 / 回响 / 织言 / 辅星 / 映迹）可按需安装
- 删掉任一功能模组，北辰照常启动
- 语音、打字两条输入通道

### 💪 对性能负责

- 语音模型在本机运行，占用取决于所选模型
- 对话推理在云端，不占本地显存
- 设置里可以换更小或更大的语音模型

---

## 🎯 功能一览

### 🎙️ 语音输入

- 按住语音键说话，松开提交识别
- 支持多种语言
- 自动修复游戏内物品、实体名称

### 💬 智能对话

- 接入自己的大模型端点
- 了解游戏内上下文（维度、血量、手持、准星等）
- 多轮对话记忆与长期记忆
- RAG：按当前游戏状态检索相关信息

### 🔊 语音输出

- 回复直接在本机合成语音
- 支持多种声音风格
- 高端模型支持音色克隆

### ⌨️ 双输入

- 不方便说话时，也可以打字对话

## 💡 我们的方式

| | 天枢 |
|---|---|
| 语音 | 本机识别 + 本机合成 |
| 对话 | 云端大模型，OpenAI 兼容端点 |
| 模型获取 | 语音模型游戏内下载；对话模型填端点与 Key |
| 交互 | 语音为主，可打字 |
| 费用 | 模组免费；对话按服务商计费 |
| 隐私 | 音频不出本机；对话文本与必要上下文发送到所配置的端点 |

> 天枢没有账号体系，也不上传诊断日志；发往模型端点的内容受该服务商的隐私政策约束。

## 🛠️ 产品架构

```
玩家语音 / 打字
      │
      ▼
听澜：语音识别 ─► 识意：文本修复 ─► 思衡：决定谁回答
      │
      ▼
辅星：记忆 + 上下文 + 回答组织
      │
      ▼
织言：云端大模型（OpenAI 兼容，流式）
      │
      ▼
回响：本机语音合成 ─► 玩家听到
```

- **北辰**：宿主，负责界面、按键、设置、世界状态与功能模组装载
- **映迹**：独立功能模组，把世界状态整理成模块可用的事实，并画出游戏内 HUD
- **本地运行时**：本地语音与向量模型随功能模组一起安装

当前平台：**NeoForge 1.21.1**；Fabric 适配尚未提供。
