# 天枢 Mod (Tianshu) 客户端数据需求全景清单
> *本清单穷尽了功能 1-9 在 `neoforge` 客户端层所需的全部底层数据，用于指导 Provider 接口设计。*
> *注：所有涉及 `ItemStack`, `BlockState`, `Vec3` 等 MC 原生类的算法，均必须在 `neoforge` 模块实现，`common` 模块仅处理纯 Java 对象或接口定义。*

## 一、 玩家自身状态
*主要消费方：功能3(导航)、功能5(听觉裁决)、功能7(熔断受击判定)*
- **空间坐标**：`Vec3` (X, Y, Z 脚部坐标)
- **视角数据**：`Yaw` (水平偏航角)、`Pitch` (垂直俯仰角)
- **生存状态**：当前血量、最大血量
- **受击状态**：最近一次受到伤害的时间戳 (Tick 级)、最后一次伤害来源
- **世界维度**：当前所在维度 Key (如 `minecraft:overworld`)
- **特殊坐标**：个人床坐标、上一次死亡坐标

## 二、 实体环境数据
*主要消费方：功能1(战术雷达)、功能5(战术雷达)*
- **基础标识**：实体 ID、`EntityType`、自定义名称
- **空间运动**：`Vec3` 坐标、三轴运动速度
- **生存与状态**：当前血量、最大血量、是否拉弓、是否潜行
- **关系与遮挡**：对玩家是否敌对 (`TargetingConditions`)、是否被方块遮挡 (射线追踪结果)
- **音频事件**：拦截到的 `SoundEvent` 注册名、发声位置坐标 (仅限高危声音，如苦力怕嘶嘶)

## 三、 世界与方块数据
*主要消费方：功能1(深度解析)、功能5(BFS寻路)、功能7(情境熔断)*
- **准星目标**：命中方块的 `BlockPos`、`BlockState`、附属的 `BlockEntity` NBT 数据
- **挖掘目标**：玩家当前正在挖掘的方块的 `BlockState` (用于判断是否为高价值方块如钻石矿)
- **局部拓扑缓冲区**：玩家周围指定半径内 (如16格) 的 `BlockState` 只读数组切片 (**红线**：必须支持增量更新 Dirty Region，严禁全量重建)
- **方块标签**：方块的 `Tag` 集合 (用于 BFS 跳过非实体障碍加速)

## 四、 背包与物品属性
*主要消费方：功能2(装备中枢)、功能4(合成定锚)、功能6(伴生对比)、功能7(寻找替代品)、功能8(垃圾清理)*
- **全量快照**：主背包 (36格)、盔甲栏 (4格)、副手栏 (1格)、快捷栏 (0-8格) 的 `ItemStack` 列表
- **物品微观属性** (针对单件物品)：
  - 基础 ID (`Item` 注册名)
  - 完整 NBT 数据
  - 附魔列表 (ID 与等级)
  - 属性修饰符 (攻击力、攻击速度等 AttributeModifier)
  - 耐久数据 (当前值、最大值)
  - 显示名称 (是否有自定义名称，功能8保护锁核心判定依据)

## 五、 配方与合成数据
*主要消费方：功能4(悬浮合成面板)*
- **目标物品全配方**：输入物品 ID，返回所有可能的合成方式列表
- **单配方详情**：
  - 配方类型 ID (如 `minecraft:crafting_shaped`、模组机器类型)
  - 输入材料矩阵 (`Ingredient` 列表，包含允许的物品 ID)
  - 输出结果 (`ItemStack` 及数量)

## 六、 渲染与 UI 上下文
*主要消费方：功能1(雷达投影)、功能3(近场锚定)、功能6(动态避让)*
- **相机矩阵**：`ProjectionMatrix` 和 `ModelViewMatrix` (**仅限**功能1的卡片牵引、功能3≤15格的锚定框需要 World-to-Screen 投影时获取。功能3远场指北针不需要)
- **窗口参数**：屏幕宽高像素值
- **原版 Tooltip 矩形**：当前帧原版提示框占据的屏幕 X, Y, Width, Height (功能6防越界计算)

## 七、 社交与外部模组生态
*主要消费方：功能9(同声传译)、功能3(导航终点)*
- **聊天队列**：最近 N 条消息 (发送者名称、消息纯文本、时间戳)
- **玩家标识**：当前客户端玩家的确切游戏名或 UUID
- **输入框状态**：聊天框是否处于打开状态
- **外部路径点**：Waystones / JourneyMap 提供的已激活路径点列表 (名称、`Vec3` 坐标、维度)
