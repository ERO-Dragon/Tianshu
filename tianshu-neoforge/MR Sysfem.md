🌐 天枢 Mod - 功能 1：全息战术 MR 系统（终极开发宪法 v3.0）
第一层：系统基建与线程红线（生死攸关）
1. 四层解耦架构
状态机：绝对大管家。仅管控 SILENT -> SCANNING -> FOCUSING 流转，绝不碰坐标和渲染。
投影仪：纯数学工具类（3D 转 2D），严禁在此处操作 ItemStack 或 NBT。
悬停侦探：运行在 ClientTickEvent (20Hz)，记录准星 Tick 差值。
统筹器：与雷达联动，取最大感知半径（MR 32格），统一下发 Provider 指令。
2. “影子快照”线程模型（绝对红线）
严禁跨线程调用任何 MC 渲染 API，违者必崩。 采用严格的异步计算与主线程绘制隔离：

子线程（算力下沉）：100% 负责所有数学计算、阻尼平滑、状态机流转、布局推挤。其产出物只能是纯基本类型的 POJO 类（如 MrCardSnapshot，仅包含 float x, y, w, h, alpha, progress 及 boolean 标志位），绝对禁止在此对象内持有 ItemStack、Vec3 等原生类。
主线程（无脑绘制）：在 RenderGuiOverlayEvent 中，主线程只做一件事：从线程安全队列中 poll() 出 MrCardSnapshot，像无情的画图机器一样调用渲染 API。主线程内禁止出现任何 if-else 逻辑判断和加减乘除运算（全部由子线程算好结果）。
第二层：空间几何与布局引擎（物理法则）
1. 伪 3D 锚定与微透明度
方向锁定：偏移方向必须在屏幕正交轴上计算，彻底消灭俯仰角翻转带来的线段悖论。
距离缩放：基于 3D 欧几里得距离 dist 计算缩放比 scale = base_dist / dist，实现近大远小。
纵深透明：卡片 Alpha 必须叠加极淡的距离衰减（如 1.0 - (dist / 32) * 0.2），增强空间感且不干扰阅读。
2. 初始线段 A->B 的“带死区力场导向”
拒绝硬切分：采用“上下死区锁死方向 + 中间 Smoothstep 平滑旋转 + 穿越正中心时依赖上一帧方向记忆划弧线”的算法，实现“保持 -> 渐变 -> 保持”的完美过渡。
3. 动态交点 C 与“鞭子效应”的精准三级拆分（核心机械结构）
第一层：原点 A。0 阻尼，死锁实体头顶实时坐标。
第二层：固定线段 A->B。0 阻尼，像刚性短棍紧跟实体。
第三层：动态线段 B->C 与卡片主体。阻尼仅作用于此（0.15f）。
鞭子真相：猛转头时，A/B 瞬间移走，卡片滞后，仅 B->C 段被拉扯变形。若阻尼拉开超阈值（如 300px），强杀旧卡片并在新位置重新触发出现动画。
4. 群体防撞：刚性虚拟锚线
禁止弹簧推挤（防抖动死循环）。
连上下边：单向强制推挤，遇阻死锁。
连左右边：穿过 C 点画无限长虚拟水平辅助线，其他卡片顶/底边直接刚性吸附排队。
第三层：动效时序与状态熔断（时间法则）
1. 帧率无关性（绝对红线）
所有 0-1 进度条递增、所有阻尼平滑（坐标、Alpha、缩放），必须乘以 deltaTime（帧间隔时间）。保证在 60Hz/144Hz/240Hz 下，物理时长绝对一致。

2. Tron-style 动效流转（基于 0.0 -> 1.0 连续浮点数）
出现：[0.0~0.3] 竖线窜出 -> [0.3~0.5] 斜向拽至 C 点 -> [0.5~1.0] 裂变拉伸成框。>1.0 后才允许文字流式浮现（防拉伸变形）。
关闭（镜像）：文字 Glitch 挤压（极速收缩裁剪罩把多行切压成一行像素块） -> 横线回缩 -> 斜线弹回 -> 竖线缩回。
错峰调度：1秒内最多 10 卡，按距离从近到远依次延迟实例化。
3. 聚焦模式 (FOCUSING) 的景深切换
主角登基：打破伪 3D 限制，平滑放大并滑动到屏幕上半区固定锚点。
群演退场不消亡：其他卡片不触发消失动画，强制进入 BACKGROUND 层级：几帧内平滑缩小至 70%-80% 并叠加深半透明遮罩。退出时平滑恢复。
4. 异常熔断拦截
软边框进出：阈值按屏幕宽高百分比（如 3%）算。Alpha 必须做阻尼平滑双向过渡。越过硬边框瞬间强杀。
遮挡反转：lineOfSight == false 后原点 A 跟随 1 秒。1 秒后播 1.0->0.0，若中途实体出掩体，目标进度瞬间切回 1.0，依靠阻尼自动掉头重展，绝无闪现。
死亡倒地：!isAlive() 瞬间切灰度滤镜，等 deathTime 结束后触发倒放消失。
第四层：渲染管线与程序化绘制（视觉表现）
1. 零贴图原则（100% 纯代码生成）
绝对禁止使用任何外部 UI 贴图（.png），全部通过基础图形 API 拼装，确保完美适配光影、资源包及任意 GUI 缩放。

2. 核心组件绘制规范
切角矩形背景：用“减法”。先画完整暗色半透明矩形，再用背景色在四角画 4 个小三角形/正方形“盖掉”直角。
切角线框：用画 1 像素宽矩形的方法拼出四条边，四角位置留空不画。
霓虹发光线（牵引线/线框）：不用贴图光晕。先画一条 3px 宽的低透明度底线，再叠加一条 1px 宽的高亮亮线，视觉即为完美发光管。
装备图标（白嫖原版）：子线程提取实体 MainHandItem 引用，主线程直接调用 Minecraft.getInstance().getItemRenderer().renderAndDecorateItem()，自动跟随玩家材质包。
怪物头像（符号化）：不截取实体贴图。推荐提取 getDropItem()（如僵尸头）用 renderItem 渲染；或直接画极简几何轮廓（如带切角的方块+两个发光菱形眼睛），彻底零耦合且极具赛博感。
血条/数值：双层 fill() 叠加（底灰+血量色插值），文字调用 Font 渲染并附加赛博风阴影色（如 Color(0, 255, 255, 100)）。
第五层：LLM 深度解析安全锁
唯一触发时机：仅当状态机切入 FOCUSING 时。
数据清洗红线：绝对禁止将模组实体的原始 NBT（数 MB）发给大模型。必须在 neoforge 模块提取出极轻量的纯文本 JSON（如 {type:"Zombie", health:20}）再下发。
