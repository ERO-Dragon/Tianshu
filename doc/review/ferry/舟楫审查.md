# 舟楫审查

2026-11-24 · Minecraft 1.21.1 · Fabric / NeoForge

当前工作树通过 Gradle `test check`、服务端工具注册、共享适配层和协议版本门禁。12 个测试任务共记录 2397 项，2385 项通过，12 项跳过，0 项失败。

## 尚待实机验证

- **舟楫单端与工具通道。** 在仅装舟楫的 Fabric / NeoForge 服上分别用原版客户端、同加载器但未装舟楫的客户端进服。核对实体注册表没有 `tianshu_ferry:walker`，`marker` 和 `stand` 仍可用。双方装舟楫时检查目录通道匹配则提供远程工具、不匹配则只保留本地功能。[联机验收矩阵](../../architecture/契约与验收.md#舟楫联机协议)
- **双端实体验收台。** 测试服和客户端都装 `tianshu_lab` 时，核对内建 walker 与验收台的 `acceptance_orb` 可生成、同步和显示。分别验证单侧缺少验收台时被该模组拒绝连接。
- **本地功能与换服。** 两个加载器的舟楫客户端均已实测进入原版服。仍需检查原版服内的本地功能，以及在舟楫服和原版服之间切换时工具目录、可用状态和实际调用是否随连接更新。
- **换世界与载体重绑。** 同一进程连续打开两个存档。验证第二个世界的服务端工具指向当前服务器，并检查模组申请的普通及玩家型 NPC 跨区块卸载、存档重启后的身份、归属、背包和装备。模块间拒绝、玩家访问规则和会话端口注销已有自动化覆盖。[身体授权测试](../../../../Tianshu-ferry/tianshu-client/src/test/java/com/rheinmetal/tianshu/client/tool/BodyAccessTest.java) · [会话注册测试](../../../../Tianshu-adapter/tianshu-adapter/1.21-1.21.1-common/src/test/java/com/rheinmetal/tianshu/mc/tool/ServerRegistrationsTest.java)
