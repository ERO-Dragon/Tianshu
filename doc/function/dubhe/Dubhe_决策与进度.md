# Dubhe 决策与进度

> 本文件回答两件事：**已经定下什么**（决策速查，代码注释引用这些编号），**还剩什么**。
> 现状：改造已完成 P1–P8 主体；下面「剩余」是仍未闭环的部分。

## 1. 验收判据（全部满足才算做完）

1. simple 的工具集**恒为** `{delegate}`。
2. 代理目录 = 内部技能 + 宿主工具（按档位过滤）。
3. 三档授权：设置页选档、每档首次使用先问玩家。
4. 办事失败对玩家说游戏内原因，不念错误码。
5. 记忆：压缩（单元驱动）与重置（水位驱动）分开，摘要块只收已移出单元。
6. 事件：五档 / 九格固定映射 / 三态，`FOLD` 只进当前窗口。
7. 对外只发布 `dubhe:search` 一个可读技能；无通用任务入口。
8. 四条架构门禁常绿；技能新增不改代理循环。
