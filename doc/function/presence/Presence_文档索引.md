## 建议阅读顺序

1. 先读模块设计，理解映迹回答什么、不回答什么。
2. 要接模块或排查活动状态，读产品活动协议。
3. 调 HUD、伙伴标记或 shader，读模块设计 §5 与 HUD 预览 README。
4. 跨模块契约以协议中心为准；历史决策看拆分实施记录。

## 写作约定

- **行为以代码为准**：字段、默认值、时序都以当前实现为准；设计文档描述意图与权衡。
- **协议只登记一次**：topic、payload 字段和投递策略在协议中心登记；本目录引用，不另立第二套。
- **HUD 预览是生成物**：改 HUD 后运行 `.\gradlew.bat :tianshu-presence:exportHudPreviewAssets`，不要手改页面里的生成块。
- **不写版本号**：文档描述当前状态，历史交给版本库。
