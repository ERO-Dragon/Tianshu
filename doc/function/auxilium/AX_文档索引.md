## 建议阅读顺序

1. **先读运行架构**：它给出模块边界与不变量，其余五篇都在这些约束里展开。
2. **再按你的任务选一篇**：改提示词看上下文编排；改记忆看记忆策略；加事件看事件系统；改委派看 Agent 运行时；接外部模块看协议中心。
3. 四篇专题互相引用同一批参数（`W`、尾部尺寸、档位、阈值），**只在各自的所有者文档里定义一次**，其余地方引用不复述。

## 写作约定

- **行为以代码为准**：数据结构、字段、默认值、时序都以当前实现为准；设计意图与权衡才来自设计稿。
- **参数只在自己那篇定义**：`W` 与尾部尺寸在上下文编排，档位/名单/类别在事件系统，打分常量在记忆策略；跨篇只引用，不重写数值。
- **不写版本号与修订说明**：文档描述当前状态，不做变更记录；历史由版本库承担。
- **不写落地路线与待办**：未实现的能力不写进契约；要加能力先改这张表之外的正文，再改代码。
- **不写自然语言到代码里**：任何面向模型或玩家的句子都在语言资源中，文档只描述槽位与纪律。
