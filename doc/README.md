# 舟楫文档

> 舟楫是基座：**三个核心**（模块宿主、协议中心、能力注册）+ **两个功能方向**（玩家辅助、自定义实体）。
> 这里只放舟楫自己的文档；跨仓库的平台与适配层文档（模块架构、多加载器与多版本、未完成事项）在主仓库 `Tianshu/doc/`。
> **不设 history**：过时的结论直接改掉，不归档——归档会让两套说法同时存在。

## 四、落点规则

一种信息只有一个落点，别处只能链接、不许复述。出现"同一件事写两遍"时，删副本。

| 信息类型 | 落点 |
|---|---|
| 设计决策与边界（该不该做） | [职责边界](职责边界.md) |
| 能力表、工具契约、共享与订阅 | [能力注册](能力注册.md) |
| 门禁、验收台、四层「可用」、待补证据 | [验收](验收.md) |
| 玩家侧有哪些工具、怎么加 | [玩家辅助](玩家辅助.md) |
| 实体侧有哪些工具、怎么加 | [实体操作](实体操作.md) |
| 实体层契约（注册、能力位、端口、写盘） | [实体](实体.md) |
| 宿主生命周期与装配 | [模块宿主](模块宿主.md) |
| 模块间通信 | [协议中心](协议中心.md) |
| 技能与说明书的写法 | [技能撰写规范](技能撰写规范.md) |
| 未修的项 | 本文 §五 |
| 平台与适配层（跨仓库） | 主仓库 `Tianshu/doc/` |

判据：**描述舟楫自己的决策、契约和内容规范的文档跟舟楫代码走；跨仓库的平台与适配层文档留主仓库。**
