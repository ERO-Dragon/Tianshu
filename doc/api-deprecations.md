## 登记方式

1. 在代码里保留旧名（`PayloadType.alias(old, new)`；capability/topic 旧名保留转发），并加 `@Deprecated`（若为 Java 类型）。
2. 在 `NeoForgeClientBootstrap` 的弃用诊断之外，本表登记一行。
3. 到达计划的移除版本（只能是 `MAJOR`）时，删除旧名与本行。
