# 智能体身体验收清单（1.21.1）

> 手工验收用。每一步都写了"做什么、期望什么"，失败时先看[智能体身体](智能体身体.md)里的判定顺序。
> 只覆盖 1.21.1 的 NeoForge / Fabric；其他版本分支没有身体实现。

## 准备

1. 单人世界，开启作弊（需要权限等级 2）。
2. 打开身体写工具的开关，默认是关的：
   - NeoForge：`<世界>/serverconfig/tianshu-server.toml` 的 `[tools]` 段，`body_actions = true`；
   - Fabric：`config/Tianshu/tools.properties`，`body_actions=true`。
3. 重启游戏，让开关生效。

## 1. 身体存在与列举

| 步骤 | 期望 |
|---|---|
| 执行 `/tianshu body list` | `no agent bodies` |
| 执行 `/tianshu body spawn marker` | 返回 `spawned agent body <uuid>` |
| 执行 `/tianshu body list` | 列出刚才的 uuid |
| 执行 `/tianshu body spawn stand` | 返回第二个 uuid；世界里出现一个悬浮的盔甲架 |

失败：命令不存在 → 命令注册没走到；`unknown body kind` → 传了 marker/stand 以外的词。

## 2. 能力边界

| 步骤 | 期望 |
|---|---|
| 让天枢调用 `body.list` | 两条记录；marker 的能力是 `LOOK`,`MOVE`，stand 多出 `ATTACK`,`INVENTORY`,`MINE` |
| 让 marker 执行 `body.mine` | `UNSUPPORTED_ACTOR`，世界不变 |
| 让 marker 执行 `body.attack` | `UNSUPPORTED_ACTOR` |
| 用一个不存在的 uuid 执行 `body.move` | `UNAVAILABLE` |

这一组验证的是"平台按能力拒绝"，不是"动作失败"。

## 3. 移动与朝向

| 步骤 | 期望 |
|---|---|
| `body.move` 指定 stand 到 5 格外的一个坐标 | 盔甲架瞬移到该坐标；结果显示落点 |
| 同一条指令把 `mode` 写成 `walk` | `FAILED`，消息说明这具身体只能传送 |
| `body.look` 指向另一个点 | 盔甲架转向该点 |

## 4. 挖掘与攻击

| 步骤 | 期望 |
|---|---|
| 把 stand 传送到一块泥土旁，`body.mine` 该方块 | 方块消失并掉落；结果里带方块 id 与坐标 |
| 对空气位置 `body.mine` | `NO_EFFECT`（`there is no block there`） |
| 把 stand 传送到一只生物旁，`body.attack` 它 | 生物受伤；结果为 `DONE` 或 `NO_EFFECT`（盔甲架无伤害时） |
| 对 6 格外的目标执行 mine/attack | `FAILED`，消息是 out of reach |

## 5. 身体背包（stand 专属）

| 步骤 | 期望 |
|---|---|
| `craft.recipe` 带 `body: <stand uuid>`，站在合成台旁 | 产物进身体背包，不是玩家背包 |
| 身体旁边没有合成台时重复上一步 | `FAILED`，消息要求 nearby crafting table |
| `container.transfer` 带 `body: <stand uuid>`，`toPlayer=true` | 物品从容器进身体背包 |
| 同一个调用改成 `toPlayer=false` | 物品从身体背包进容器 |
| `block.machine` 带 `body: <stand uuid>` 给熔炉加燃料 | 燃料取自身体背包，熔炉开始燃烧 |

这一步是"玩家指挥一具有背包的身体"，玩家自己的背包不受影响。

## 6. 已知限制（预期内的失败）

| 现象 | 原因 |
|---|---|
| 重启后 `/tianshu body list` 为空 | 注册表与背包都是内存态，未做持久化 |
| `block.interact` 对任何身体都返回 `UNSUPPORTED_ACTOR` | 没有载体声明 `USE`：原版方块交互需要 `Player` |
| 跨维度 `body.move` 被拒 | 只支持同维度传送 |
| 身体所在区块未加载时动作被拒 | 不做强制加载 |
