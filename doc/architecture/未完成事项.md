## 已完成（本轮收口）

- **实体层**：`api/entity` 按职责拆分与改名；`EntityActor.playerLike()` 身份声明；`body.*` 改
  `BODY_WRITE`（默认关、`EVERYONE`、归属判定）；实体类型以纯数据声明（`body_types.json`）并在注册期扫描；
  形状 × 身份两条轴（`BodyKind` / `BodyIdentity`）在两端实现，玩家型身体 NeoForge 用 `FakePlayer`、
  Fabric 自建 `ServerPlayer` + 回环连接，均已实机验证。
- **作弊级动作**：14 个动作是服务端工具（`FULL` / 默认关 / 需 operator），执行只走
  `ServerActionExecutionPort`；工具的启用状态跟随各自的服务端开关，配置重载后目录同步刷新；
  `server.say` 是 `LOCAL` / `CONSERVATIVE` / 默认开的客户端聊天工具。旧的请求通道、三个动作包、
  `ServerActionClient`、`ServerActionStatus`、`ClientServerActionPort` 已全部删除。
- **MCP**：两侧整体删除（2026-11-16），将来以独立扩展模组实现；待修清单 §3 仅留历史记录。
- **验收台**：47 条用例 + 自检，NeoForge 与 Fabric 各一轮，均为 **44 通过 / 2 跳过 / 0 失败**。
- **文档瘦身**：`architecture` 由 19 篇收敛到 7 篇，15 篇原文进 `doc/history/`。
