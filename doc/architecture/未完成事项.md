## 设计 A：辅星文字输入口 ↔ 听澜转联动

**为什么两件事必须一起做**：听澜改联动的前提是辅星有第二条输入通道。在此之前翻转，得到的形态是
"能装、但没有任何东西把对话投递给它"。

### 输入口形态：独立按键 + 复用聊天栏输入位

按下按键打开一条与聊天栏同款的输入条，空白时显示灰色引导文本（走语言键，不硬编码）；回车发送、
Esc 取消、空输入不提交。**不改写聊天，也不拦截 `/` 命令**。

曾考虑 `/` 未知命令回落（首词不是已知命令就转交辅星），放弃的原因：可发现性差，而且必须额外加
"编辑距离 ≤ 1 按原版未知命令处理"的保护，否则拼错指令会被静默吞成对话。

归属与听澜的语音键同构：**按键与屏幕在 adapter，输入语义在辅星**（辅星实现端口，adapter 调它）。
键位默认另选（语音键占 `V`），玩家可在按键设置改；辅星缺席时不注册该键。

### 内部抽象：输入瞬时快照 vs 慢上下文

投递今天带 12 个字段，但它们不该同等对待：

| 类别 | 字段 | 归属 |
|---|---|---|
| **输入瞬时快照** | 文本（`repairedText`）、IR 命中（`objectMatches` / `moduleMatches`） | 只有输入方知道，辅星事后采不回来 |
| **语音可选增强** | `interactionHints`（说话那一刻的准星 / 手持 / 交互键） | 语音由听澜送；**文字输入没有这个**，辅星自行补齐 |
| **慢上下文** | 维度、事实键、背包、实体引用等（`contextSnapshot` 的绝大部分） | 辅星已有 `AXContextCollector.collect(scope, request)` 自采，投递里那份是重复的 |
| **身份** | `sessionId` / `playerId` / `turnId` / `requestId` / `expireAtMillis` | 由会话与超时策略给出，不由输入给出 |

**文字输入只有文本**，所以 `hints` 在 `AXDialogueInput` 里是可空的。为空时辅星用已有的
`AXDynamicFactClient` 向映迹发 `PRESENCE_CONTEXT_QUERY` 补齐——`PresenceContextSnapshot` 已经带
`heldItemId` / `heldItemDisplayName` / `crosshairTarget` / `interactionKeyDown` / `attackKeyDown` /
`sneaking` / 背包，不需要新增端口。

两条路径的语义差别只有一处：自采拿到的是**回合开始那一刻**，投递里的是**说话那一刻**。文字输入两者等价；
语音里说长句到仲裁有秒级延迟，所以语音仍值得保留 hints，但它退化成"有就更准"，不再是必需。

结论：投递瘦身为「输入瞬时快照 + 身份」，慢上下文由辅星自采；文字输入在**提交那一刻**采同样的快照，
两条路径因此一致。这也是第 0 步的答案。

代价要盯着：提示内容的来源从"投递"换成"自采"，事实与维度部分必须对比确认没有退化。

### 依据：字段的真实依赖

早前"辅星只读 5 个字段"的说法是错的（只统计了变量名 `payload` 的访问）。真实依赖是 **12 个字段**，
它们今天混在一起投递：

| 字段 | 次数 | 用途 |
|---|---|---|
| `sessionId` | 19 | 会话与回合标识 |
| `interactionHints` | 9 | 手持物 / 准星命中 / 交互键 / 目标距离 |
| `requestId` | 8 | 关联与回合身份 |
| `turnId` | 7 | 回合身份 |
| `contextSnapshot` | 5 | 维度、事实键、实体引用 |
| `playerId` | 4 | 提示与记忆归属 |
| `objectMatches` | 3 | 玩家说的词（展示给模型的正是"原话"） |
| `expireAtMillis` | 3 | 过期判定 |
| `displayNames` | 2 | id → 本地化名 |
| `matchedEntityRefs` | 2 | 准星实体 |
| `repairedText` | 2 | 真正的输入文本 |
| `normalizedText` | 1 | 仅诊断 |

按"谁采得回来"分成上面那三类之后，辅星侧的输入类型只剩这些：

```java
record AXDialogueInput(
    String text,                              // 已修复（语音）或原样（文字）
    String sessionId, String playerId, String turnId, String requestId,
    DialogueInteractionHints hints,           // 可空：语音带"说话那一刻"，文字为空→辅星自采
    Map<String, String> displayNames,
    List<AXMatchedObject> objectMatches,      // 辅星侧值类型；文字输入时为空
    long expireAtMillis)
```

慢上下文（维度、事实、背包）不在里面——辅星用 `AXContextCollector` 自采。
