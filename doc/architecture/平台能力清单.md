# 平台能力清单

> 北辰与游戏本体的交互面。按 **侧（客户端 / 服务端）× 读写** 组织；
> 状态：`已有` / `缺` / `不做`。新增能力先在这里登记，再开端口。

## 0. 分类

| | 读（快照/事件） | 写（效果/操作） |
|---|---|---|
| **客户端** | 玩家/世界/实体/背包/效果/准星快照 | 本地效果：界面、HUD、聊天栏、action bar、toast、title、声音 |
| **服务端** | 权威事件、服务端状态快照 | 世界变更（动作）、广播 |

三条不对称：

1. 客户端"写"是本地效果，无权威；服务端"写"是权威变更，需要服务端组件。
2. "读"分推（事件订阅）与拉（快照请求），端口要分别提供。
3. 广播虽然属于服务端操作，但需要客户端发起请求，因此是**双端能力**，不是纯服务端能力。

已定决策：

- **附近实体不做**（成本高、收益低；准星目标已覆盖对话场景）。
- **服务端动作的配置只做开关**（`enabled`），不加权限档位与频率档位；默认关闭。
- **广播是双端功能**：客户端请求 + 可选服务端组件；服务端缺失时降级为仅本地输出或明确失败。

## 1. 客户端只读（已有）

| 能力 | 载体 | 说明 |
|---|---|---|
| 玩家 id | `ClientGameContextPort.playerId()` | 无会话时为空 |
| 玩家状态 | `GamePlayerStatus` | 血量/最大血量/饥饿/等级 |
| 背包 | `captureInventory()` | 物品 id、显示名、数量、堆叠上限 |
| 装备 | `captureEquipment()` | 护甲/副手 |
| 效果 | `captureEffects()` | id、显示名、剩余 tick、等级、是否增益 |
| 准星实体 | `GameTarget` | id、类型、显示名、距离、`present` |
| 世界环境 | `GameWorldEnvironment` | 雨/雷、时间、生物群系 |
| 交互切片 | `GameInteractionContext` | 维度、屏幕类型、手持、穿戴 id、使用/攻击键、潜行 |

## 2. 客户端只读（缺，P1）

| 能力 | 建议形状 | 备注 |
|---|---|---|
| 方块命中 | 方块 id、坐标、是否可交互 | 与实体准星分开 |
| 容器内容 | 仅玩家已打开的容器 | 本机可见数据，不涉及他人 |
| 坐标/朝向/游戏模式 | 位置、yaw/pitch、模式 | 快照 |
| 经验进度/饱和度/吸收 | 0–1 进度、饱和、吸收值 | 补 `GamePlayerStatus` |
| 客户端计分板 / 玩家列表 | 本机可见范围 | 需要脱敏时另议 |
| Boss 条 | 名称、进度、颜色 | 客户端读取面 |

**不做**：附近实体。

## 3. 客户端表现（缺，P1-写）

| 能力 | 语义 | 备注 |

## 5. 服务端只读（P2）

| 能力 | 状态 | 备注 |
|---|---|---|
| 权威事件 | 已有 `GameFactCollector` | 合成/拾取/钓鱼/驯服/伤害/击杀/死亡/方块/坐骑/效果/经验/交易 |
| 服务端时间/天气 | 缺 | 权威值，客户端估算不可靠时用 |
| 结构发现 | 缺 | 客户端没有结构数据 |
| 玩家列表公开信息 | 缺 | 只给公开字段，不给他人的背包/位置 |

## 6. 服务端操作（P3）

### 6.1 动作（权威变更）

| 项 | 约定 |
|---|---|
| 配置 | 每个动作一个 `enabled` 开关，默认关闭 |
| 校验 | `enabled=false` 直接拒绝，不执行 |
| 权限 | 第一版：需要服务端组件且执行者为 OP；后续再扩展 |
| 回执 | 结果：`OK` / `DENIED` / `DISABLED` / `FAILED(reason)` |
| 幂等 | 请求带 id，重复请求返回同一结果，不重复执行 |
| 候选动作 | 给物品、传送、切时间/天气、生成实体（先定这几个，不做万能命令） |

### 6.2 广播（双端）

| 项 | 约定 |
|---|---|
| 链路 | 客户端请求 → 可选服务端组件 → 广播 |
| 受众 | 第一版：全服；半径/队伍后续 |
| 内容 | 文本 + 发送者标识；长度上限待定 |
| 频率 | 服务端限流（具体值待定） |
| 降级 | 服务端缺失：明确失败，或配置允许时仅本地聊天栏 |
| 配置 | 同样是 `enabled` 开关 |

## 7. 元能力（已有）

事件订阅（`TickSignals` / `InputSignals` / `WorldEvent`）、注册表/字典（`NamedObjectDictionary`）、网络通道（内部）、模组列表（`InstalledMods`）、配置、语言。

## 8. 明确不做

- 附近实体；
- 原始 `Level` / `Entity` / `ItemStack` 穿过 api；
- 万能 `runCommand(String)`；
- 模拟输入（伪造按键/鼠标）；
- mixin 进 MC 内部；
- 其他玩家的背包/位置/私有数据；
- 打开链接。
