# 工具层游戏内验收清单

> 用途：在真实客户端/服务器里逐项确认能力层的行为。CI 已覆盖契约、编解码、分发、限流、能力读取、
> skill/resource/prompt、MCP 假服务器；本清单只列**只有游戏内才能确认**的部分。
>
> 建议顺序：单人（开作弊）→ 单人（关作弊）→ 专用服务器；每项记录"通过/失败 + 现象"。

## 0. 准备

- 开发客户端：用 lab 启动（dev-only），设置页 →「仲裁测试台」→「能力自检」，
  应看到各 kind 计数、内置 skill/resource/prompt 读取结果与 `inventory.inspect` 的通道结果；
  这一步不经过天枢，只验证能力层本身。

- 客户端与服务端装同一版本；服务端装 Tianshu 服务端组件。
- 写工具默认关闭：先在 `config/Tianshu...` / `[tools]` 打开要测的开关，玩家需为 operator。
- 单人开作弊（op）；另做一轮关作弊的非 op 对照。
- 检查日志：写工具执行应有审计行 `write tool ...`；无异常堆栈。

## 1. 查询类工具（只读，默认开）

| # | 操作 | 期望 |
|---|---|---|
| 1 | 问"圆石能做什么" | 调 `recipe.query`，回答配方；**绝不念出工具 JSON** |
| 2 | 问"石头属于哪些标签" | 调 `tag.query`，返回标签列表 |
| 3 | 问"我背包里有什么" | 调 `inventory.inspect`，结果与背包一致 |
| 4 | 问"僵尸掉什么" / "橡木原木的掉落" | 调 `loot.query`，返回物品列表 |

## 2. 写工具（保守档，需 operator + 开关）

| # | 操作 | 期望 |
|---|---|---|
| 5 | 对着按钮/拉杆/门说"打开它" | `block.interact` 成功；门/按钮状态改变 |
| 6 | 箱子旁说"把箱子里的 X 拿 3 个" | `container.transfer` 移动 3 个；容器与背包一致 |
| 7 | 工作台旁说"用背包材料合成 X" | `craft.recipe` 消耗材料、产出正确 |
| 8 | 熔炉旁说"加燃料/放原料/取产物" | `block.machine` 三步各自正确 |
| 9 | 非 op 玩家重复 5–8 | 应被拒（`NO_PERMISSION`），世界不变 |
| 10 | 关掉对应 `[tools]` 开关后重复 | 应 `DISABLED`，世界不变 |

## 3. 风险分级

| # | 操作 | 期望 |
|---|---|---|
| 11 | 只读档（`ToolAutonomyGate` 设 READ_ONLY，若已接线） | 写工具从目录消失、调用被拒 |
| 12 | 保守档（默认） | 上述四个写工具可用；未来 FULL 工具不可见 |
| 13 | FULL 档（API/配置） | 特权工具才可见；仍需 operator + 开关 |

当前没有设置页入口，模式通过 API/后续配置设置；此项可先只验证默认保守档。

## 5. MCP

### 客户端（消费外部 MCP）

| # | 操作 | 期望 |
|---|---|---|
| 20 | `config/Tianshu/mcp.json` 配一个 HTTP MCP server，重启 | 日志/工具目录出现 `mcp:<server>.<tool>` |
| 21 | 让天枢调用该工具 | 远程执行；结果回灌；失败有明确错误 |
| 22 | 配 stdio server（command 数组） | 子进程启动；工具可用；关闭客户端后进程结束 |
| 23 | 断开 MCP server 后调用 | 明确失败，不挂起、不影响其他工具 |

### 服务端（暴露能力）

| # | 操作 | 期望 |
|---|---|---|
| 24 | `mcp.json` 开 `server.enabled`，重启 | 只有 `127.0.0.1:<port>` 可访问 |
| 25 | 用 MCP 客户端 initialize / tools/list | 只有 `read_capability`；无写世界工具 |
| 26 | 读 skill/resource/prompt | 返回文本；非法 id/工具类 id 被拒 |

## 6. 边界与失败

| # | 操作 | 期望 |
|---|---|---|
| 27 | 远程服务器未装服务端组件 | 服务端工具立刻 `UNSUPPORTED_SIDE`，不等待超时 |
| 28 | 调用中退出世界 | 不挂起；无残留 pending；重进后状态正常 |
| 29 | 快速连续调用同一工具（脚本/连点） | 超过限流出现 `RATE_LIMITED`，服务端不卡顿 |
| 30 | 构造超大结果（大容器/长列表） | 客户端拿到结构化失败或截断，不超时、不崩溃 |
| 31 | 写工具执行后看日志 | 有审计行；被拒绝的调用没有审计行 |
