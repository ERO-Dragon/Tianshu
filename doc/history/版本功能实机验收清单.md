## 2. 工具验收

设置 → 【听澜】仲裁测试台 → 工具控制台。

| 工具 | 参数 | 期望 |
|---|---|---|
| `minecraft:recipe.query` | `{"outputItemId":"minecraft:iron_pickaxe","limit":3}` | `ok=true`，`result.recipes` 非空，配方 id/原料/产物正确 |
| `minecraft:recipe.query` | 1.21.2+ 同参数 | 同样返回真实配方，不出现 `UNAVAILABLE` |
| `minecraft:craft.recipe` | `{"recipeId":"minecraft:stick"}`，站在工作台旁，背包有木板 | `ok=true`，消耗 1 个原料，获得产物；缺料时 `ok=false` 且不消耗 |
| `minecraft:block.machine` | `{"x":…,"y":…,"z":…,"operation":"insert_fuel","playerSlot":0}` | 合法燃料才会插入；非燃料返回失败 |
| `minecraft:block.machine` | `insert_input` / `take_output` | 可熔炼物才插入；产物可取出 |
| 写工具开关 | 服务端 `[tools]` 默认关闭 | 未开启时 `DISABLED`；开启且 operator 才执行 |

每项记录：工具 id、参数、返回 JSON、是否改变世界。
