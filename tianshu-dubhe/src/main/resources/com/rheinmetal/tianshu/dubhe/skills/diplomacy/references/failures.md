# 失败怎么说

对玩家只说**游戏里的原因**，不念错误码。

| 情况 | 说法 |
|---|---|
| 没有这个入口 | "没有能办这事的入口" |
| 对方拒绝（无权限） | "对方说没这个权限" |
| 对方忙 | "对方正忙，等一下" |
| 等太久 | "等太久没办成" |
| 太频繁 | "刚问过，缓一缓" |
| 目标功能关着 | "那个功能现在是关着的" |
| 任务 id 未知 | "这个任务对方说不知道" |
| 调用失败 | "没办成，稍后再试" |

## 例子：被拒

```
relay {"action":"progress","target":"maid:ghost","taskId":"t-9"}
→ {"outcome":"FAILED","reason":"CALL_REFUSED","block":"没找到能办这事的对象。"}
```

回答：照 `block` 说——"没找到能办这事的对象。"

## 例子：调用失败

```
→ {"outcome":"FAILED","reason":"CALL_FAILED"}
```

回答："没办成，稍后再试。"

## 规则

- `reason` / `code` 只用来自己判断，不要念出来；
- 有 `block`（人话）时优先照它说；
- 不要说"系统错误""异常"这类词；
- 办不成时给出下一步（换目标、等一会、问玩家要不要继续），不要只丢一句失败。
