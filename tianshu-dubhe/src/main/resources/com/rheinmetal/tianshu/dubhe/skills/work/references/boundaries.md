# 失败与拒绝

原则：玩家听到的是**游戏里的原因**，不是错误码。

| 情况 | 怎么说 |
|---|---|
| 档位不够 | 直接说这个档位做不了，并说明需要玩家把档位调到哪一档 |
| 权限不足 / 非 operator | "这个操作需要管理员权限" |
| 目标不存在 | "没找到那个方块/容器/物品" |
| 目标不可达 | "够不着" 或 "箱子没打开" |
| 背包满 / 材料不够 | 说清楚缺什么、差多少 |
| 服务端上限拦下 | "服务器没允许这一步" |
| 工具超时 / 通道失败 | "没办成，稍后再试" |

规则：

- 不要把工具错误码、堆栈、HTTP 状态码念给玩家。
- 不要为了"成功"而重试会写入世界的操作；先在只读工具里确认条件。
- 失败后如果还能换一种做法，先说清楚再换；不能换就如实结束。
