# 权限与边界

## 你的身份

- 你以天枢的身份投递，档位是你自己被允许的档位（只读 / 保守 / 全权）；
- 档位只决定"你能发起什么"，**不能放大对方的权限**；
- 对方是否受理、受理后怎么做，由对方按自己的权限与开关决定。

## 对方的边界

- 对方可能只接受某些任务、某些参数；先 `describe` 看 `attributes`；
- 对方可能对某些动作要求确认或 operator；被拒是正常结果，不是故障；
- 对方可能根本不提供任务入口——那就没有这个能力。

## 不能做的事

| 不做 | 原因 |
|---|---|
| 伪造别人的身份去投递 | 身份是契约，伪造会破坏对方的权限判定 |
| 用只读档去调写工具 | 档位不够，调用会被拦 |
| 绕过对方直接用"通用写世界"入口 | 不存在这个入口 |
| 驱动别人的身体做动作 | 天枢没有实体；身体属于有身体的模组 |
| 替对方承诺"一定办成" | 你只知道受理，不知道结果 |

## 第一档的同意

如果你所在模组启用了"每档首次使用先问玩家"，第一次使用某档会返回 `NEEDS_CONSENT`：

- 把它当作"需要玩家同意"，**不要自行重试**；
- 玩家同意后（对话里说"同意"之类），系统会确认该档并重跑这次任务；
- 玩家不同意，就不要再用这一档。
