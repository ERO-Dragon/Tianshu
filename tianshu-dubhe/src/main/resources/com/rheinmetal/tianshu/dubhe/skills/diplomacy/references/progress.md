# 查进度：三态，不轮询

```
action   = progress
target   = 对方注册的读工具 id
taskId   = 投递时拿到的回执
```

## 例子：三种回答

```
relay {"action":"progress","target":"maid:reader","taskId":"t-9"}
→ {"outcome":"OK","taskId":"t-9","progress":"RUNNING"}
```

回答："还在搬。"

```
→ {"outcome":"OK","taskId":"t-9","progress":"DONE"}
```

回答："搬完了。"

```
→ {"outcome":"OK","taskId":"t-9","progress":"UNKNOWN"}
```

回答："女仆没说进展，要不我再去问问？"（**不猜"办完了"**）

## 返回三态

| 进度 | 含义 | 对玩家怎么说 |
|---|---|---|
| `RUNNING` | 正在办 | "还在办" |
| `DONE` | 办完了 | 说结果（如果对方给了说明） |
| `UNKNOWN` | 对方没说/不认识 | "对方没说进展"——**不许猜成办完** |

## 什么时候查

只有两种情况：

1. **玩家问起**（"那事办得怎么样"）；
2. **对方主动回投了报告**（那时用报告，不必再查）。

## 不许做的事

- 不许轮询（每轮都查、定时查、循环查）——那会变成第三个触发源，持续打扰别人；
- 不许把 `UNKNOWN` 当 `DONE`，也不许把一直 `RUNNING` 说成"马上就好"；
- 不许自己编一个 `taskId` 去查。

## 查完怎么回

- `RUNNING`：一句话，别展开；
- `DONE`：说结果；有后续动作就问玩家要不要办；
- `UNKNOWN`：如实说；可以顺带说"要不我再问问"。但要记住：**再问 = 再查一次（一次，不是循环）**。
