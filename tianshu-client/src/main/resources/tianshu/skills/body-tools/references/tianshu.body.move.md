# 移动

`tianshu:body.move` 的目标是**世界坐标**（`x/y/z`），不是相对位移。

| 模式 | 需要 |
|---|---|
| `walk`（默认） | 生存级 |
| `fly` | 特权级 |
| `teleport` | 特权级 |

- 动之前用 `body.status` 确认起点，别按"向前三格"算目标。
- 走不到先看三件事：隔着墙、脚下没有落脚点、目标在未加载区块里。
- 返回里有实际到达的位置与是否被卡住；瞬移后以返回值为准，不要沿用旧坐标。
- **不跨维度**：维度不符会被拒，拒绝消息里会同时给出两个维度。

## 范例

```json
{"id":"tianshu:body.move","args":{"x":118,"y":52,"z":-30}}
```

```json
{"ok":true,"result":{"reached":{"x":118.5,"y":52,"z":-30.5},"blocked":false},"durationMs":412}
```

`blocked: true` 表示没走到：先 `body.scan` 看脚下与前方，而不是重发同一个坐标。
