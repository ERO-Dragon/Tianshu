# 特权级：飞行、瞬移与串步骤

这一级不是"更快的生存级"。它对应的是玩家靠作弊或命令才能做到的事，所以默认被服务器上限挡住：
上限是 `conservative` 时，这些调用会被明确拒绝，并告诉你需要什么。

## 飞：`body.move` 带 `mode=fly`

- 飞行期间身体不受重力，可以停在半空；
- 目标点是世界坐标；到达后可以继续 `walk`，也可以再飞；
- 掉进虚空/未加载区块的检查依然生效：飞不出世界里。

## 瞬移：`body.move` 带 `mode=teleport`

- 跨距离移动，但**不跨维度**：维度不符会被拒，并同时给出两个维度；
- 瞬移后身体的位置以返回值为准，别沿用旧的坐标算下一步；
- 瞬移到未加载区块会触发生成，耗时更长，失败时看是不是"区块还没准备好"。

## 串步骤：`body.sequence`

按顺序跑 `{action, args}`，每步的 `action` 就是上面那些工具名去掉 `tianshu:` 前缀（例如 `body.mine`）。

| 规则 | 说明 |
|---|---|
| 中途失败即停 | 返回 `failed` 步号、动作名与原因，不会"尽力而为"继续 |
| 能取消 | 长序列在步边界可以被取消，已完成的步不会回滚 |
| 不判断 | 它不做条件分支；需要"看情况"的流程自己一步步调 |

**什么时候用它**：流程固定、每步参数事先算得出来（扫→走→挖→捡）。
**什么时候不用**：下一步取决于上一步的结果（挖到了什么、周围有没有敌人）。

## 一条提醒

特权级能力越强，失败时的"半完成"越难收拾：飞到半空体力用尽、瞬移到岩浆里都是真实结果。
不确定时先用生存级做一遍，确认路线再上特权级。
