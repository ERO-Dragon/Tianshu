# 生存级：玩家不靠作弊能做的事

这一级的目标是"看起来像一个熟练玩家在操作"。所有失败都会带原因，读完原因再决定下一步。

## 走：`body.move`

| 参数 | 说明 |
|---|---|
| `x` `y` `z` | 目标**世界坐标**（不是相对位移）。先用 `body.status` 确认起点 |
| `mode` | `walk`（默认，生存级）/ `fly` / `teleport`（后两个要特权级） |
| `body` | 可选，指定哪一具 |

返回里有实际到达的位置和是否被卡住。走不到时先看是不是隔着墙、脚下没有落脚点、或目标在未加载区块里。

## 看：`body.look`

给 `yaw`/`pitch`，或者给一个目标坐标让它转过去。挖之前先看是必要的——`body.mine` 作用在视线与距离内的方块上。

## 扫：`body.scan`

按半径列出周围的方块与实体，带坐标与 id。它是"我周围有什么"的唯一可靠来源，比用坐标猜好。

## 挖：`body.mine`

| 返回 | 含义 |
|---|---|
| 方块被破坏 | 真的掉了；有些方块需要正确的工具才会掉落 |
| `距离太远` | 目标不在可触及范围内，先 `body.move` 靠近 |
| 工具不合适 | 换 `body.equip` 换成对的工具；用错工具可能什么都没有 |

## 打：`body.attack`

目标实体 id。注意：攻击会真的造成伤害，也会真的拉仇恨。不确定时先 `body.scan` 看周围有多少同类。

## 捡：`body.pickup`

捡起附近掉落的物品。背包满了会失败，先 `body.inventory` 看有没有空间。

## 丢 / 装备：`body.drop` / `body.equip`

`body.equip` 按槽位装备，`slot` 与 `body.inventory` 的索引一致。手上没有东西时 `body.mine` 与 `body.attack` 都很弱。

## 给：`body.give`

把身体背包里的东西交给够得着的目标（玩家或容器）。距离不够会失败——先靠近。

## 读状态：`body.status` / `body.inventory` / `body.list`

- `body.status`：位置、维度、血量、饥饿、手上物品、是否存活；
- `body.inventory`：槽位 → 物品与数量，`body.equip` 的 `slot` 就用这套索引；
- `body.list`：所有身体及其 id。

**这三条是"先看一眼"的成本最低的方式。** 任何要动手的操作之前先看，比失败后猜便宜。
