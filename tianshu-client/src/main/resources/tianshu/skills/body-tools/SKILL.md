# 实体工具

身体是一具真实的玩家实体：它受物理、碰撞、触及距离和区块加载的约束。这里没有"瞬间完成"，失败都是真原因——
先读原因再决定下一步，不要换个参数重试同一个错误。

## 动手之前

1. **哪一具**：`tianshu:body.list` 列出身体；不带 `body` 参数时作用于调用者自己那具。
2. **在哪**：`tianshu:body.status` 给位置、维度、血量、饥饿、手上物品；`tianshu:body.scan` 给周围有什么。
3. **被允许做到哪**：生存级只做玩家不靠作弊能做的事；飞行与瞬移要特权级。服务器上限更低时会被明确拒绝，
   并说明需要什么——不要靠改参数绕过。

## 让失败可读的四条

- **真的调用，不要叙述**：世界只因工具执行而改变；说"做好了"不等于做了。
- **读失败原因**：够不着、背包满、目标类型不对、级别不够，是四件不同的事、四种不同的下一步。
- **坐标是世界坐标**：动之前用 `body.status` 确认起点，别按"向前三格"算。
- **串步骤**：`tianshu:body.sequence` 按顺序跑 `{action, args}`，第一步失败就停并说出是哪一步。
  它适合固定路线；下一步取决于上一步发现了什么时，不要塞进它。
