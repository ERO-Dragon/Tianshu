# 全权档（FULL）

作弊类动作；需要 operator、各自开关与服务端上限。**每次调用前都要向玩家确认。**

| 类别 | 说明 | 参数 |
|---|---|---|
| 传送 | 把玩家/实体送到坐标或目标 | 见 `tianshu:tool.catalog` |
| 天气 | 晴/雨/雷 | 见 schema |
| 时间 | 设置昼夜 | 见 schema |
| 给物品 | 直接发放物品 | 物品 id + 数量 + 目标 |
| 生成实体 | 生成生物/掉落物 | 实体 id + 坐标 |
| 广播 | 系统公告（与 `server.say` 不同） | 文本 |
| 经验 / 游戏模式 / 状态效果 / 难度 / 游戏规则 | 规则级修改 | 见 schema |

## 调用前

1. 用只读工具确认目标存在（坐标、实体、玩家）；
2. 一句话说明将要发生什么，等玩家同意；
3. 调 `tianshu:tool.catalog` 确认该动作的参数，不要猜；
4. 失败时按游戏原因回报；不要重试会重复写入的操作。

## 与保守档的区别

- `server.say` 是保守档：以玩家身份说一句；
- `server.broadcast` 是全权档：系统公告；
- 两者不要混用，也不要把全权动作说成"顺手做了"。
