# 全权动作

这些动作会改变世界或玩家状态，属于 `FULL` 档：需要 operator、对应开关、服务端 autonomy ceiling；每次使用前向玩家确认。

| 类别 | 说明 |
|---|---|
| 传送 | 把玩家或实体送到坐标/目标 |
| 天气 | 切换晴雨雷 |
| 时间 | 设置昼夜 |
| 给物品 | 直接发放物品（不经过合成/容器） |
| 生成实体 | 生成生物/掉落物 |
| 广播 | 系统公告（`server.broadcast`，与 `server.say` 不同） |
| 经验 / 游戏模式 / 状态效果 / 难度 / 游戏规则 | 游戏规则级修改 |

调用前：

1. 用只读工具确认目标存在（坐标、实体、玩家）；
2. 一句话说明将要发生什么，等玩家同意；
3. 失败时按游戏原因回报，不重试会重复写入世界的操作。

具体 id、参数、返回以 `tianshu:tool.catalog` 为准。
