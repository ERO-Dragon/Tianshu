# 北辰 · Beichen

北辰是天枢（Tianshu）的本体。界面、按键、设置页、世界状态、模块宿主、本地音频桥和诊断都在这里；语音识别、语音合成、云端对话、对话大脑与 HUD 由可选的功能模组提供，装谁是谁。

> 功能模组都需配合北辰运行；不装任何功能模组时北辰也能正常启动，只是没有任何功能。

**游戏版本**：NeoForge 1.20.1 起、Fabric 1.20 起，每个 Minecraft 版本一个 jar（1.20.x / 1.21.x / 26.x 各自的版本线见[文档索引](../doc/README.md)）。
**加载器**：NeoForge / Fabric
**依赖**：`tianshu_libs`（本地运行时库）——必需；功能模组——可选。

---

## 功能

- **模块宿主** — 功能模组自己注册、自己装配；删掉任一功能模组，北辰照常启动。
- **设置页** — 暂停菜单进入「天枢 AI 控制台」。每个模组贡献自己的页面，草稿与保存是一笔事务，关闭前会提醒未保存的修改；内核页带一个调试开关（仅开发版可见）。
- **按键与输入** — 按住 `V` 说话；装了辅星后，按 `H` 打开文字输入条。功能模组也可以声明自己的按键，统一由北辰注册到「按键设置」。
- **HUD 宿主** — 功能模组在自己的 HUD 图层上绘制内容；图标位置可以拖动调整。没装使用 HUD 的模组时，不产生每帧开销。
- **本地表现** — 聊天栏、action bar、toast、title 与本机声音，供功能模组在本地提示或播报。
- **世界上下文** — 血量、饥饿、等级、背包、装备、效果、方块命中、打开的容器、坐标朝向、玩家列表，按需读取。
- **世界事件** — 把合成、击杀、死亡、拾取、交易、驯服、效果、成就、聊天、维度切换、容器打开、Boss 等游戏事实整理成事件流，供功能模组消费（NeoForge 与 Fabric 各自能取到的子集不同）。
- **服务端动作（可选，默认全关）** — 给物品 / 传送 / 设置时间 / 设置天气 / 生成实体，以及全服广播。每个动作一个开关，执行者需要 OP，请求带 id 幂等，广播有冷却。
- **诊断** — 统一写 `logs/tianshu-diagnostics.log`：`WARN` / `ERROR` 恒记录，`TRACE` / `DEBUG` / `INFO` 只在调试开关打开时记录；正式版不会把调试信息打进游戏内聊天栏。
- **音频桥** — 麦克风采集与本地播放的设备枚举、选择与生命周期由北辰提供，语音模组只管用。
- **第三方接入** — 其他模组可探测北辰、注册指令词、提交模块状态、贡献设置页；NeoForge 走注册事件，Fabric 走静态入口，两者等价。接入方式见《外部接入指南》。

## 配套的功能模组

| 模组 | 作用 | 依赖 |
|---|---|---|
| **听澜** | 语音识别、识别结果修复、**思衡**（对话仲裁） | 必需映迹 |
| **回响** | 本地语音合成 | 映迹可选 |
| **织言** | 云端大模型（OpenAI 兼容端点，流式） | 映迹可选 |
| **辅星** | 对话大脑：上下文、记忆、回合编排、回答呈现 | 必需织言与映迹；听澜、回响可选 |
| **映迹** | 世界状态整理、HUD 图层、上下文查询 | —— |

全部装上是完整形态；只装其中几个也能跑，缺的能力会安静降级（例如没装回响时只显示文字回答）。

## 设置与配置

- 入口：暂停菜单 →「天枢 AI 控制台」。
- 内核配置：`config/tianshu-client.toml`（只有调试开关）。
- 功能模组配置：`config/Tianshu/module/<moduleId>.properties`，由各模组自己维护。
- 服务端动作开关：`config/tianshu-server.toml`，默认全关；存档内可用 `serverconfig/tianshu-server.toml` 覆盖。

## 隐私

北辰没有账号体系，也不上传诊断日志。语音音频不出本机；对话文本以及与回答相关的上下文会发送到你自己配置的模型端点，受该服务商隐私政策约束。
