# 北辰 · Beichen

北辰是天枢（Tianshu）的基座：功能模组装在它上面运行，界面、按键、设置、世界状态和本地音频都由它提供。天枢的功能来自可选的功能模组，装谁是谁。

> 功能模组都需要北辰，不能单独使用；不装任何功能模组时，北辰也能正常启动。

**游戏版本**：NeoForge 1.20.1 起、Fabric 1.20 起，每个 Minecraft 版本一个 jar（版本线见[文档索引](../doc/README.md)）。
**加载器**：NeoForge / Fabric
**依赖**：`tianshu_libs`（本地运行时库）——必需；功能模组——可选。

---

## 提供什么

- **统一的设置页** — 暂停菜单里的「天枢控制台」，各功能模组把自己的设置页挂在这里。
- **基础能力** — 按键、HUD、音频、聊天栏与本地提示，功能模组直接使用，不必各自实现。
- **世界感知** — 把玩家状态、背包、准星目标与游戏事件整理给需要的模组。
- **服务端动作（可选）** — 给物品、传送、时间与天气等，默认关闭，需要管理员开启。
- **诊断日志** — 出问题时按文档反馈日志。

## 配套的功能模组

| 模组 | 作用 | 依赖 |
|---|---|---|
| **听澜** | 语音识别、识别结果修复、**思衡**（对话仲裁） | 必需映迹 |
| **回响** | 本地语音合成 | 映迹可选 |
| **织言** | 云端大模型（OpenAI 兼容端点，流式） | 映迹可选 |
| **辅星** | 对话大脑：上下文、记忆、回合编排、回答呈现 | 必需织言与映迹；听澜、回响可选 |
| **映迹** | 世界状态整理、HUD 图层、上下文查询 | —— |

全部装上是完整形态；只装其中几个也能跑，缺的能力会自动降级（例如没装回响时只显示文字回答）。
