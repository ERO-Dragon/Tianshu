# 天枢 · Tianshu

天枢是可扩展的 AI 助手：北辰（Polaris）是它的基座，负责界面、按键、设置、世界状态与本地音频；功能模组装在基座上运行。

**游戏版本**：NeoForge 1.20.1 起、Fabric 1.20 起，每个 Minecraft 版本一个 jar（版本线见[文档索引](../doc/README.md)）。
**加载器**：NeoForge / Fabric
**依赖**：`tianshu_libs`（本地运行时库）——必需；功能模组——可选。

---

## 北辰提供什么

- **统一控制台** — 暂停菜单里的「天枢控制台」，功能模组的设置页挂在这里。
- **基础能力** — 按键、HUD、音频、聊天栏与本地提示。
- **世界感知** — 玩家状态、背包、准星目标与游戏事件。
- **服务端动作（可选）** — 给物品、传送、时间与天气，默认关闭，需要管理员开启。
- **诊断日志** — 出问题时按文档反馈。

## 配套的功能模组

| 模组 | 作用 | 依赖 |
|---|---|---|
| **听澜** | 语音识别、识别结果修复、**思衡**（对话仲裁） | 必需映迹 |
| **回响** | 本地语音合成 | 映迹可选 |
| **织言** | 云端大模型（OpenAI 兼容端点，流式） | 映迹可选 |
| **辅星** | 对话大脑：上下文、记忆、回合编排、回答呈现 | 必需织言与映迹；听澜、回响可选 |
| **映迹** | 世界状态整理、HUD 图层、上下文查询 | —— |
