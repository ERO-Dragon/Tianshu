# Tianshu (天枢)

天枢就是那名同伴本人——负责决定该说什么。每一轮它先看你正站在哪、手里拿着什么、身上有什么状况，想起你以前说过的话和偏好，留意刚刚在世界上发生了什么，然后向模型要一个回答，再把这段回答交给回响念出来。它不是命令行，也不是搜索框：你说话，它回答，像一个人。

**游戏版本**：不限。以单个通用 jar 分发，同时带 NeoForge 与 Fabric 入口，各游戏版本的兼容性由舟楫适配。
**加载器**：NeoForge / Fabric
**运行于**：天枢客户端，与织言、映迹一起运行；听澜与回响可选。
**外部接入**：其它模组可以提问、补充上下文或发布事件，见[外部接入指南](../EXTERNAL_INTEGRATION_GUIDE.md)。

---

## 它能给你什么

- **记得你** — 你说过的事、你的偏好、这个存档里发生过的大事，都会留下，并在合适的时候被想起。
- **知道当下** — 天气、面前的生物、刚捡起的东西、正在下的矿，都可以进到这一轮对话里。
- **不吵你** — 世界里的动静会安静地并进下一句回答，而不是随时弹出来打断你。
- **说得出口** — 回答由回响念出来，也可以边听边看文字。
- **对别的模组开放** — 其它模组可以找它说话，也可以把自己的事件交给它播报。

## 一句话怎么变成回答

1. 你开口（打字或语音），这一轮开始。
2. 它把刚才攒下的世界事件先并进记忆——你刚看到的事不会丢。
3. 它取回相关的记忆，看一眼你现在的状态。
4. 它把这一切整理成一次提问，交给织言。
5. 回答回来，正文记进历史，再由回响念出来。

## 记忆

短期记忆是最近这些话，长期记忆是它自己整理的要点、事件和你的偏好。旧内容会被压缩成摘要，存档越玩越久，也不会变成一堆流水账。每个存档、每位玩家的记忆各自独立。

## 世界事件

内置四十多种事件，从天气变化到你第一次挖到钻石，按重要程度分档。哪些该说、哪些只记下、哪些连记都不用，都可以在设置里选。默认偏安静：它只在值得的时候开口。

## 委派

当场上有能干活的能力时，天枢可以把子任务交出去，等结果回来再并进回答——你看到的仍然是一段连贯的话，而不是一串工具日志。
