# AX 天枢助手文档索引

### 快速摘要

- 对话入口

  - AX 是天枢的长期对话助手，只有 IA 仲裁选择 AX 并实际投递新的 delivery 后，才开始一轮回答。
  - 每轮输入都会先整理玩家文本，再获取当前游戏情境并检索近期对话、长期记忆和可用知识。

- 上下文与回答

  - AX 按信息完整性组织当前输入、动态环境、知识命中、近期对话和玩家记忆，再在整体 token 预算内组装 Prompt。
  - 组装完成后调用 LLM 的 CHAT 链路生成回答，并把流式正文同步交给界面和 TTS。
  - Prompt 的裁剪以完整对话、完整记忆块和完整知识命中为基本单位，token 数用于控制整体软边界。

- 记忆

  - 近期对话保留完整轮次，超出窗口的旧对话会在后台逐步压缩、提炼和建立检索索引。
  - 同一世界的记忆会跨退出游戏和重启客户端继续保留，新版本继续读取已经存在的 AX 记忆。
  - 游戏环境事件先作为当前情境使用，只有符合记忆策略的内容才会转成长期事实。

- 输出与打断

  - 已经展示或播放的回答内容会保留到近期对话，即使后续回答被取消也不会丢失已发生的交互。
  - 允许打断时，只有新的 IA delivery 再次选中 AX，才会取消旧回答并停止 AX 自己的 TTS。
  - 禁止打断时，新 delivery 会被拒绝且不排队，当前回答继续完成；ASR 说话活动本身不改变 AX 回合。
