# 实验台 · Lab

实验台是给开发者用的小工具，不是给玩家装的模组。它会往世界里放三个"陪练"，专门用来试一件事：当有好几个声音同时想说话时，这一轮到底归谁——你正看着的生物、手里拿的东西，还是你刚喊的那个名字。

**游戏版本**：不限。以单个通用 jar 分发，各游戏版本的兼容性由舟楫适配。
**加载器**：NeoForge / Fabric
**运行于**：天枢客户端，与听澜一起；不面向玩家的存档。

---

## 它能给你什么

- **三种认领并排可看** — 一个按准星认领，一个按手持物，一个按唤醒词，各有优先级，谁赢一眼就清楚。
- **看得见的租约** — 赢下之后能保持多久可以切换，包括"不保持"，用来看归属是过期还是延续。
- **唤醒词可改** — 默认一组，实验台页面里可以替换。
- **不自带台词** — 陪练只回答自己的名字与归属，不掺别的内容。
