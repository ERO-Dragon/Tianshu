# 映迹 · Presence

映迹是舟楫（Ferry）基座上的 HUD 与上下文能力：把世界状态整理成模块可用的事实，汇总各模块发布的产品活动，并把它们画进游戏画面。

**游戏版本**：不限。映迹以单个 universal jar 分发，同时带 NeoForge / Fabric 入口；各 Minecraft 版本的兼容性由天枢适配。
**加载器**：NeoForge / Fabric
**运行环境**：舟楫（Ferry）基座上的客户端模组，服务端不需要安装。
**依赖**：舟楫（Ferry）与百工（Foundry）——均为必需；HUD 的落笔、GUI 门控与位置编辑器由舟楫提供。
**第三方接入**：其他模组可以把自己的状态发布到 HUD，也可以查询映迹整理的世界状态；见[产品活动协议使用文档](../doc/function/presence/Presence_产品活动协议使用文档.md)。

---

## 功能

- **动态图标** — 着色器逐帧绘制的流体球：空闲时小而安静，聆听时最大并向外扩散涟漪，思考回到参考尺寸与参考极光，回复时表面呈肥皂泡式起伏；另有一套光线步进预设。
- **伙伴标记** — 由仲裁模块写入的预中标人或中标人图标与租期环，开口之前就知道这一轮归谁。
- **世界快照** — 维度、血量、饥饿、背包、装备、药水、准星目标与世界环境，按字段组回答查询。
- **事件窗口** — 把一秒内的游戏事件聚合成一条带计数的记录，交给订阅方。
- **交互上下文** — 准星、主手、装备、潜行、交互键与屏幕类型一变就推送摘要。
- **显示可调** — HUD、状态文字、动态图标分别开关；图标 16–96 px；两套预设；带位置编辑器。

## HUD 状态

| 主状态 | 画面 |
|---|---|
| 空闲 | 小球、弱极光，不显示文字 |
| 正在听你说 | 球体最大，外侧两道扩散涟漪 |
| 正在加载 | 球收成点，再展开成六个液体点 |
| 正在思考 | 参考尺寸与参考极光 |
| 正在回复 | 与思考同尺寸，极光强度同聆听，表面肥皂泡式起伏 |
| 重连 / 启动失败 | 沿用加载与后台任务的视觉，只有文字不同 |

多个活动并存时，主状态按固定优先级取一个；后台任务不抢主状态，只用图标右下角的小点表示。离开世界时活动清空。

## 世界状态与事件

映迹读取当前世界并整理成平台无关的事实：玩家状态、背包与装备、准星与目标、药水效果、维度与环境；游戏事件按秒聚合成一条记录，每组带计数。这些信息既回答其他模块的查询，也通过 `PRESENCE.WORLD_EVENT` 发给订阅方。

## 第三方接入

- **产品活动**（`PRESENCE.ACTIVITY`）— 声明「正在做什么、什么时候结束」；同一模块可以同时公开多个任务，结束一个不影响其他任务。
- **上下文查询**（`PRESENCE.QUERY_CONTEXT`）— 按需索取世界快照，只读需要的字段组。
- **世界事件**（`GAME.WORLD_EVENT`）— 发布后由映迹聚合成一秒窗口的 `PRESENCE.WORLD_EVENT`。
- **伙伴标记**（`PRESENCE.PARTNER`）— 由仲裁方写入，映迹只负责渲染图标与租期环。

## 显示设置

设置页在「天枢控制台 · 映迹」，持久化在 `config/Tianshu/module/module.presence.properties`。可以开关 HUD、状态文字与动态图标，切换视觉预设、调节图标大小，并用位置编辑器拖动锚点。
