# 织言 · Weaving

织言是天枢 AI 能力基座上的一项基础能力：把"和大模型打交道"做成一块公共能力。它把调用方的消息送到 OpenAI 兼容端点，把回答边生成边送回；另有一份可选的本地向量能力，能把文本算成向量、存进本机并做检索。记忆怎么记、检索结果怎么用，都是调用方的事——织言只提供通道和数据面。

> 织言是基座上的一个独立能力模组，需要单独安装；装好后与天枢客户端一起运行，但调用方不限于天枢。

**游戏版本**：不限。以单个通用 jar 分发，同时带 NeoForge 与 Fabric 入口，各游戏版本的兼容性由天枢适配。
**加载器**：NeoForge / Fabric
**运行于**：与天枢客户端一起运行；作为独立能力模组单独安装。
**服务对象**：所有模组。天枢（AX）是调用方之一，其它模组可以直接接入。
**外部接入**：见[外部接入指南](../EXTERNAL_INTEGRATION_GUIDE.md)。

---

## 它能给你什么

- **用你自己的模型** — 填上密钥就能用，想换随时换，不必重装。
- **检索可以完全留在本机** — 向量模型可选：装了就在本机算向量、断网也能检索；不装也不影响聊天。
- **各管各的** — 每个模组登记自己的库，可见性由登记者决定。
- **长对话也接得住** — 按所选模型的窗口公布预算，塞得下大量世界信息。
- **对开发者开放** — 任何模组都可以调用它：问模型、算向量、存取与检索，见上面的外部接入指南。

## 一项能力，三种用法

- **问一次模型** — 给一段消息，拿回一次回答；要流式就边生成边收，也可以中途取消。
- **算向量、存取条目** — 把文本写成向量存进本机的库，之后按相关度取回；只为一次查询临时算也可以，不落盘。
- **量一下** — 发请求前估算 token、把文本转成向量、看一眼当前模型的运行状态。

## 它不做的事

织言不管记忆，也不替调用方决定内容：提示词组装、检索结果注入、人格、对话归属、工具调度，全都归调用方。它只保证消息可靠地送出去、碎片按顺序送回来、向量和检索在本地可用。向量模型没装或起不来时，云端通道照常工作，只有检索与向量查询报不可用，且检索会退化为纯词法匹配。
