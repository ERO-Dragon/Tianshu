天枢事件九宫格

九宫格 = 矩阵（行 = 频率，列 = 三态）；五个处置是一维数组，由固定映射表（反对角线同值）相连。 每条事件在它可达的每一行各占一格（频率只降不升，所以 RARE 事件有三格、FREQUENT 只有一格）。 共 0 条 / 0 格：已接通 0 · 可接 0 · 待定 0 · 不做 0
